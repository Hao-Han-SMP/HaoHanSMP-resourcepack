# HaoHan menu icons

All menu controls use `minecraft:paper` with the following `CustomModelData` values.

| CMD | Texture | Intended use |
| --- | --- | --- |
| `900001` | `previous_active` | previous active |
| `900002` | `previous_disabled` | previous disabled |
| `900003` | `next_active` | next active |
| `900004` | `next_disabled` | next disabled |
| `900005` | `recipe_arrow` | recipe arrow |
| `900006` | `close` | close |
| `900007` | `info` | info |
| `900008` | `confirm` | confirm |
| `900009` | `cancel` | cancel |
| `900010` | `back` | back |
| `900011` | `refresh` | refresh |
| `900012` | `search` | search |

Values 900001–900012 are reserved for server GUI controls. Add new icons after this range and update both this file and `MenuIcon.java`.
